Ejercicio 01

El Filtro de Bordes

Aplicamos una operación de convolución manual usando un kernel de Sobel. Esto nos permite "ver" las grietas o bordes de una pieza mecánica antes de usar IA.

  • Concepto: Kernel 3x3
  • Librería: OpenCV
import cv2 import numpy as np # 1. Definir Kernel Sobel (Detector de bordes verticales) kernel_sobel = np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]]) # 2. Cargar imagen en escala de grises img = cv2.imread('pieza_metalica.jpg', 0) # 3. Aplicar Convolución resultado = cv2.filter2D(img, -1, kernel_sobel) # 4. Mostrar resultado cv2.imshow('Bordes Detectados', resultado)

Ejercicio 03

Segmentación Semántica

Ya no solo detectamos "dónde" está el objeto, sino "cuántos píxeles" ocupa. Crítico para medir áreas de corrosión o defectos de superficie.

# Usamos modelo especializado en segmentación model_seg = YOLO('yolov8n-seg.pt') results = model_seg('metal_oxidado.jpg') for r in results: # Extraer máscaras binarias masks = r.masks if masks is not None: # Calcular área del defecto (suma de píxeles activos) area_defecto = masks.data.sum() print(f"Área Afectada: {area_defecto} px")
